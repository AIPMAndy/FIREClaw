## 🎯 什么是 FIREClaw？

**FIREClaw** 是一个 AI 驱动的财务自由规划工具，帮助用户制定个性化的 FIRE 实现路径。

> **FIRE** = **F**inancial **I**ndependence **R**etire **E**arly（财务自由，提前退休）

不是理财课程，不是投资建议，而是一个 **7×24小时在线的财务自由规划师**。

## 📖 FIRE 基础知识

### 什么是 FIRE？

**FIRE** 是 **Financial Independence, Retire Early** 的缩写，意为"财务自由，提前退休"。

核心理念：
- 通过高储蓄率和明智投资，积累足够的资产
- 当被动收入能覆盖生活支出时，实现财务自由
- 不再需要为钱工作，可以自由选择生活方式

### FIRE 的几种类型

| 类型 | 说明 | 储蓄率 |
|------|------|--------|
| **Lean FIRE** | 极简生活，低支出 | 50-60% |
| **FIRE** | 标准财务自由 | 50-70% |
| **Fat FIRE** | 富裕型 FIRE | 70%+ |
| **Barista FIRE** | 半退休，兼职工作 | 40-50% |
| **Coast FIRE** | 提前储蓄，后期自由 | 30-40%（前期） |

### 4% 法则

FIRE 社区广泛使用的经验法则：

> 当你积累的资产达到年支出的 25 倍时，可以安全退休。

**计算公式：**
```
FIRE 数字 = 年支出 × 25
```

例如：年支出 10 万 → FIRE 数字 = 250 万
